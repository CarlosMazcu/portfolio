Perspective Landscape (Code Profiling)

role
Solo project
stack
C · SDL 1.2 · Linux
result
≈ 0.03 ms per landscape update

Animated perspective point-cloud landscape implemented in C and rendered with SDL 1.2 on Linux. I profiled the core routine (DoEffect) and optimized memory access and arithmetic in the hot loop, reducing the landscape computation time to approximately 0.03 ms on the target hardware.
